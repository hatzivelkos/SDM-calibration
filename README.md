# SDM Calibration

Reproducibility materials for the manuscript  
**“Pareto-Front Based Parameter Selection in the Simple Divergence Minimizer”**  
by Aleksandar Hatzivelkos.

## Overview

This repository contains the Wolfram Language implementation, reproducibility notebooks, and numerical outputs used in the manuscript.

The study considers profile-dependent calibration of the parameter $p$ in the Simple Divergence Minimizer (SDM). The main specification uses first-place support (`TopSupport`) as the vertical support signal in the compromise–support plane. A robustness analysis uses an alternative pairwise-majoritarian signal (`PairwiseSupport`) on exactly the same simulated preference profiles.

## Requirements

The computations were performed in **Wolfram Language 14.2**.

No external Wolfram packages are required.

## Reproducing the main results

Open the notebooks in numerical order and evaluate all cells from top to bottom.

### 1. Main experiment

Run `notebooks/10_MainExperiment.nb`.

This notebook generates the canonical simulation sample and performs the main analysis using `TopSupport`.

The experimental design is:

- number of voters: $n=51$
- number of candidates: $m \in \{3,5,7\}$
- bloc-balance parameter: $\lambda \in \{0.50,0.60,0.70,0.80\}$
- within-bloc noise: $\eta \in \{1,2,3\}$
- replications per parameter cell: 200
- number of parameter cells: 36
- total number of simulated profiles: 7200
- random seed: `123456`
- calibration interval: $p \in [1,20]$

The notebook exports the canonical profile-level results and parameter-cell summaries to the `output/` directory.

### 2. Main analysis

Run `notebooks/11_MainAnalysis.nb`.

This notebook reads the canonical results generated by the main experiment and reproduces the numerical material used in the manuscript, including:

- the illustrative calibration example
- frequencies of the geometric regimes
- the distribution of the calibrated parameter $p^\ast$
- the manuscript heatmaps
- comparisons with the fixed baselines $p=2$ and $p=\log_2 3$

The corresponding tables and figures are written to `output/tables/` and `output/figures/`.

### 3. Pairwise-support robustness analysis

Run `notebooks/12_PairwiseSupportRobustness.nb`.

This notebook evaluates the calibration procedure using `PairwiseSupport` as an alternative vertical support signal.

The robustness analysis is paired profile by profile with the main analysis. The notebook reconstructs the same 7200 simulated profiles using the same random seed and verifies that they reproduce the canonical `TopSupport` outcomes before applying the alternative signal.

The resulting profile-level data and compact paired robustness summaries are written to the `output/` directory.

## Reproducibility details

The main experiment uses the explicit random seed `123456`.

The two-pole profile generator uses opposite reference rankings. For each ballot, within-bloc noise is introduced through sequential uniformly random adjacent swaps.

The calibration search is performed in the transformed coordinate $u=1/p$, using:

- initial grid size: 26
- three local refinement steps
- refinement factor: 6
- initial refinement half-width in $u$: 0.1
- deterministic tie-breaking in favor of the smaller $p$
- degeneracy tolerance: $10^{-12}$

These settings are stated explicitly in the reproducibility notebooks.
